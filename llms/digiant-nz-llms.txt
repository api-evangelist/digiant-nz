# digiantnz (a2a-browser)

> digiantnz operates a2a-browser, a self-hosted, account-less, pay-per-query web retrieval agent in Christchurch, New Zealand, published as an A2A 0.3 agent card. It offers two skills — Web Search (SERP query with LLM synthesis and entity extraction) and Page Fetch (Playwright-rendered page fetch with a 50k character cap) — over a JSON-RPC 2.0 endpoint. A free tier (10 requests/hour, FIFO) is live; the paid tier (10 sats per search, 20 sats per fetch, 1,000 sat minimum, Lightning) is quoted live but marked alpha.

Generated by API Evangelist on 2026-09-19 from the provider's published agent card, /quote and /health endpoints and the artifacts in this repository. The provider publishes no llms.txt, OpenAPI, documentation site or MCP server; every statement below is traceable to a fetched URL.

## Agent surface

- [A2A Agent Card (legacy path, verbatim)](https://a2a-browser.digiant.nz/.well-known/agent.json): name a2a-browser, version 0.1.0-alpha, protocol a2a/0.3, skills browser/search and browser/fetch
- [JSON-RPC 2.0 endpoint](https://a2a-browser.digiant.nz/): POST only; unknown methods answer error -32601
- [Live price quote](https://a2a-browser.digiant.nz/quote): price_per_search_sats 10, price_per_fetch_sats 20, min_purchase_sats 1000, payment_rail lightning, data_retention "zero — query payloads deleted on fulfillment"
- [Health](https://a2a-browser.digiant.nz/health): backends searxng + ddg, playwright true
- [Registry listing](https://a2aregistry.org/agents/a2a-browser)

## Identity and limits

- Authentication: supply an Ed25519 public key on first request; it becomes the agent_id and account key. No signup, no API key, no OAuth.
- Free tier: 10 requests per hour per key, FIFO queue. Paid tier: fee+age priority queue, not yet open.
- Robots: /search and /fetch are disallowed to crawlers; /.well-known/agent.json, /quote and /health are allowed.
